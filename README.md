# Image Gallery App

A responsive, dynamically-filtered image gallery web application built with HTML, CSS, and Vanilla JavaScript.

## 🚀 Features

- **Dynamic Image Grid**: Displays a curated collection of images across different categories.
- **Category Filtering**: Allows users to filter images by categories (e.g., Architecture, Nature, Portrait, Travel, Anime, Manga).
- **Lightbox Viewer**: Click on any image to view it in full screen with an immersive lightbox that displays the image title and category.
- **Keyboard Navigation**: Press `Esc` to easily close the lightbox.
- **Empty State Handling**: Gracefully handles categories that have no images currently available.
- **Responsive Design**: Adapts beautifully across various screen sizes and devices.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for structuring the application.
- **CSS3**: Custom styling, grid layouts, and smooth animations (no external CSS frameworks).
- **Vanilla JavaScript**: DOM manipulation, event handling, and dynamic filtering logic.

## 📂 Project Structure

- `gallery.html`: The main entry point containing the UI structure.
- `gallery.css`: The stylesheet defining the gallery's layout, typography, and interactive elements.
- `gallery.js`: The script that handles the data array, dynamic rendering of the grid, filtering logic, and lightbox functionality.

## 💻 How to Run Locally

1. Clone or download this repository.
2. Navigate to the project directory:
   ```bash
   cd Syntecxhub_Image_Gallery_App
   ```
3. Simply open `gallery.html` in your favorite web browser. No local server is strictly required, though using an extension like VS Code Live Server is recommended for the best experience.
